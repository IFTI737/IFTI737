### 🛡️ VisionGuard

An AI platform that turns existing CCTV cameras into 24/7 monitoring for homes, farms, shops and construction sites. I created the product, lead the team and designed the full system architecture.

[![Live Demo](https://img.shields.io/badge/Live-Demo_v1-2B90FF?style=for-the-badge&logo=vercel&logoColor=white)](https://visionguard-ui-three.vercel.app/)

- ⚙️ NestJS + PostgreSQL REST API with a rule engine, incident grouping and risk scoring
- 🚨 Alert chain that escalates from in-app alerts to Telegram to phone calls until someone responds

- 📡 Telegram Bot snapshot alerts and live WebRTC camera streaming
- 👥 Role-based team access and Redis/BullMQ job queues

### 💬 অনুভূতি · Bangla Sentiment Pro

A full-stack NLP platform for **Bangla and Banglish** text. It detects the script and routes each input to one of three transformer models I fine-tuned, then returns the sentiment, six emotion scores and the words that carried them.

[![Live App](https://img.shields.io/badge/Live-App-2B90FF?style=for-the-badge&logo=vercel&logoColor=white)](https://bangla-sentiment-pro-psi.vercel.app)
[![API Docs](https://img.shields.io/badge/API-Docs-009688?style=for-the-badge&logo=fastapi&logoColor=white)](https://iftekhar737-bangla-backend.hf.space/docs)
[![Models](https://img.shields.io/badge/Models-Hugging_Face-FFD21E?style=for-the-badge&logo=huggingface&logoColor=black)](https://huggingface.co/Iftekhar737)

- 🧠 Three fine-tuned models: BERT, BanglaBERT and XLM-RoBERTa
- 🎯 ~91% sentiment accuracy, and 6-class emotion classification (~70% Bangla, ~62% Banglish)
- 🔎 Word-level explanations that show how much each word mattered
- 📊 Bulk CSV analysis (product reviews, customer feedback), YouTube comment analysis and a mood journal
- ⚙️ Next.js frontend on Vercel and a Dockerized FastAPI backend on Hugging Face Spaces, with a public REST API

<summary><h2>🧪 Research & Other Projects</h2></summary>

| Project | Description |
|---|---|
| 🗑️ **Urban Waste Detection with Explainable AI** | Curated and annotated a ~12,000-image, 9-class waste dataset from Bangladesh. Benchmarked YOLO26, RT-DETR-L and Faster R-CNN (best: RT-DETR-L, ~83.4% mAP@0.50) and explained model errors with Grad-CAM++ and Eigen-CAM. |
